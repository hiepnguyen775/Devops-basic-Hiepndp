# 01 — Linux

> Nền móng của mọi thứ phía sau — mọi công cụ DevOps đều chạy trên Linux.

---

## 🎯 Học xong bạn làm được gì

- Điều hướng, quản lý file và tiến trình không cần tra cứu
- Phân quyền đúng: user, group, chmod, chown
- Đọc log bằng journalctl và quản lý dịch vụ systemd
- Sao lưu **có kiểm chứng** và khôi phục được

```text

├── labs/        ← code và file cấu hình bạn viết khi làm LAB
├── exercises/   ← bài tập tự làm thêm
└── notes/       ← ghi chép của riêng bạn
```
